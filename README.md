# 电路维修 - 管理员“技忆”恢复训练 v1.1.7

> **《明日方舟：终末地》同人逻辑解谜小游戏**  
> *Arknights: Endfield Fan-Made Logic Puzzle Game*

---

## 🧩 游戏简介 | About

干员们在对管理员的终端进行例行维护时，发现了一些神秘的记忆碎片。你需要通过**拖放、旋转不同形状的彩色方块**，填满受损的电路网格，使每一行、每一列的指定颜色格子数量恰好等于目标值。唯有精确修复所有电路，才能唤醒管理员的“技忆”。

*A routine terminal maintenance revealed mysterious memory fragments. You must **drag, rotate, and place colored blocks of various shapes** to fill the damaged circuit grid, matching the target counts for each row and column. Only by perfectly restoring every connection can the administrator's memories be recovered.*

## 🎮 如何游玩 | How to Play

1. 在浏览器中打开 `index.html` 即可开始（无需安装任何软件）
2. 底部候选区**点击/拖拽**方块到网格上
3. 按 `R` 键或右键旋转方块
4. 让每种颜色在每行、每列的格子数等于左上角/左侧的提示值
5. 所有行列都匹配后即为通关！

> 详细操作指南请查看游戏内的“使用说明”按钮。

*Simply open `index.html` in your browser. No installation required.*

---

## 📱 手机操作指南 | Mobile Controls

- **选择方块**：点击底部候选区的方块（高亮即选中）
- **放置方块**：点击网格空白处进入预览，然后点底部“放置”
- **拖拽移动**：也可直接按住方块拖到网格上
- **重新拿起**：点击已放置的方块可重新摆放
- **预览调整**：预览状态下可旋转、拖动调整位置
- **菜单**：左上角 ☰ 按钮可拖拽移动，点击打开功能菜单
